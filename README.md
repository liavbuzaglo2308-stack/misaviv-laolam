# מסביב לעולם

משחק קופסה גאוגרפי בעברית, ל־1–4 שחקנים על מסך אחד.

**לשחק עכשיו:** https://liavbuzaglo2308-stack.github.io/misaviv-laolam/

- זורקים קובייה ומתקדמים על מפת העולם, מצפון אמריקה ועד הדגל באנטארקטיקה.
- צבע המשבצת קובע את הקלף: כחול – שאלות ידע, ירוק – ניווט, צהוב – חידות ואתגרים, אדום – הפתעות בדרך.
- תשובה נכונה: עוד משבצת קדימה. טעות: נשארים במקום.
- מי שמגיע ראשון לדגל מנצח.

נבנה במסגרת מטלה בקורס "מתודות בח.ב.פ", המכללה האקדמית בית ברל.
